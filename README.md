# 🎵 Symphony Pose - Rhythm Game

**Symphony Pose** เป็นเกมบนเว็บ (Web-based Rhythm Game) ที่ผสมผสานแนวเกมกดตามจังหวะดนตรีเข้ากับเทคโนโลยี Machine Learning ผู้เล่นจะต้องใช้ท่าทางร่างกายผ่านกล้องเว็บแคมในการกดรับตัวโน้ตที่ตกลงมาในแต่ละเลนให้ตรงจังหวะเวลา โดยตัวเกมขับเคลื่อนด้วยปัญญาประดิษฐ์จาก **Teachable Machine (TensorFlow.js)**

---

## ✨ ฟีเจอร์หลัก (Features)
* **ควบคุมด้วย AI (AI-Powered Controls):** ตรวจจับการเคลื่อนไหวแบบ Real-time ผ่านเว็บแคม
* **ระบบ 3 เลน 5 ท่าทาง (3 Lanes, 5 Poses):** แบ่งออกเป็น 3 เลน และเพิ่มความท้าทายด้วยการแยกท่าทางตามสีของโน้ต
* **ประเภทของโน้ต 2 รูปแบบ:**
  * **Short Note (บล็อกสั้น):** ทำท่าทางให้ตรงจังหวะใน Hit Zone แล้วจบ
  * **Long Note (บล็อกยาว):** ทำท่าทางให้ตรงและค้างท่าไว้จนกว่าบล็อกจะไหลผ่านไปหมด
* **ระดับความยากต่อเนื่อง (Progressive Difficulty):** ความเร็วและอัตราการเกิดของโน้ตจะเพิ่มขึ้นตามระยะเวลาที่เล่น

---

## 🎮 วิธีการเล่นและระบบสีโน้ต (How to Play)
ผู้เล่นต้องสังเกตเลนและสีของบล็อคโน้ตที่ตกลงมา แล้วทำท่าทางให้ถูกต้องในจังหวะที่โน้ตตกลงมาถึง **Hit Zone** (กรอบด้านล่าง)

* **เลนซ้าย (Left Lane):**
  * 🟥 **บล็อกสีแดง:** ทำท่า **"ยืดแขนด้านซ้าย"**
  * 🟦 **บล็อกสีน้ำเงิน:** ทำท่า **"เอียงคอด้านซ้าย"**
* **เลนกลาง (Center Lane):**
  * 🟨 **บล็อกสีเหลือง:** ทำท่า **"ยืดแขนตรงๆ"**
* **เลนขวา (Right Lane):**
  * 🟥 **บล็อกสีแดง:** ทำท่า **"ยืดแขนด้านขวา"**
  * 🟦 **บล็อกสีน้ำเงิน:** ทำท่า **"เอียงคอด้านขวา"**

> ⚠️ **เงื่อนไข Game Over:** หากทำท่าไม่ตรงกับสี/เลน หรือทำท่าไม่ทันจนโน้ตหลุดกรอบ Hit Zone เกมจะหยุดทันทีพร้อมสรุปคะแนนและเวลาที่เล่นได้

## 📁 โครงสร้างไฟล์ (File Structure)
* `index.html` - โครงสร้างหน้าเว็บและส่วนแสดงผล UI ทั้งหมด
* `style.css` - การจัดเลย์เอาต์และการตกแต่งหน้าจอ
* `script.js` - ระบบคำนวณการตรวจจับท่าทาง (AI), ระบบเกม (Game Logic) และการเรนเดอร์ Canvas
